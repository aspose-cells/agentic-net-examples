# Workbook Merger Examples

This folder contains **Aspose.Cells for .NET** code examples related to:

Workbook Merger


## Purpose

These examples demonstrate common **Aspose.Cells APIs** used when working with:

- Workbooks
- Worksheets
- Cells
- Formulas
- Charts
- Data operations


## Example Files

Each `.cs` file demonstrates a specific task related to **Workbook Merger**.

Example:

create-a-workbook.cs


## Required Namespaces

Most examples will require:

using Aspose.Cells;


## Common Pattern

Typical Aspose.Cells workflow:

Workbook workbook = new Workbook();

Worksheet sheet = workbook.Worksheets[0];

Cells cells = sheet.Cells;


## Output

Examples may generate:

- XLSX files
- PDF files
- CSV files
- Images

Output files are written to the working directory.
- combine-multiple-workbooks-into-a-single-workbook-and-output-the-result-in-xlsx-.cs
- import-workbooks-from-any-supported-format-and-combine-them-into-a-single-newly-.cs
